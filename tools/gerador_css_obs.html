CSS gerado

Cole em Propriedades da fonte → CSS personalizado de uma Browser Source apontando para https://conferenciaweb.rnp.br/sala/<slug>. Dê "Ativar interação" uma vez para entrar como convidado. Os temas Discord e StreamYard vêm dos seus próprios css_custom_discord.css / css_custom_v0.1.css, então a transparência funciona de verdade aqui: sobrescreve as --color-* do cliente.
Proveniência dos seletores. ✔ = aparece no seu css_custom*.css ou no código da ponte, logo já provado no DOM real da RNP. ✎ = derivado por mim dos padrões deles (ex.: webcamItemName) — se o nome não estilizar, inspecione e troque o seletor. Classes com [class*="…"] dependem do hash de versão do BBB.
