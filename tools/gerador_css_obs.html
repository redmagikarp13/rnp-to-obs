CSS gerado

⛔ O CSS NÃO se aplica ao portal conferenciaweb.rnp.br/sala/<slug>. O OBS injeta o "CSS personalizado" somente no frame principal — em obs-browser/browser-client.cpp, BrowserClient::OnLoadEnd faz if (frame->IsMain() && bs->css.length()) e então anexa um <style> ao head daquele frame. Nessa URL o documento principal é o portal Rails (/conference/rooms/<slug>/invite_userid), e o cliente BBB (html5client / host Mconf) roda num iframe filho — para onde o CSS do OBS nunca chega. Conferido no HTML do portal: 0 ocorrências de data-test, #cameraDock ou html5client. É a mesma razão pela qual a ponte precisa de find_active_bbb_frame em server.py para achar o frame real da reunião.
  • Use os endpoints da ponte (recomendado): são overlays prontos, transparentes e dispensam injetar CSS — /cameras/grid, /presentation, /stage (presets cameras-only, slide-only, grid-libras…), /libras, /chat e /tv. Eles já cobrem os 5 Modos de Cena daqui.
  • O CSS abaixo só funciona se a Browser Source carregar o cliente BBB como documento principal (ex.: um deployment BBB em que o html5client é a URL de topo). Aí sim: Propriedades da fonte → CSS personalizado.
